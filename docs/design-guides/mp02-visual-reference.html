MP-02 · Tournament analysis desk — decision reference

The single selected direction for MP-02, presented as a Storybook-style review concept: a separate token overview, typescale specimen, feedback matrix, and one restrained combined composition. This is a decision aid only — it is not production UI and implies no shipped surface.

Settled decisions reflected here:
  • Dark Material 3; conceptual palette from seed #3F51B5; Tonal Spot; standard contrast — pending replacement/validation against the official Theme Builder export and explicit WCAG verification.
  • Balanced density; spacing scale 4 / 8 / 12 / 16 / 24 / 32 / 48; restrained radii 4 / 8 / 12 (default 8).
  • Tonal surfaces and fine borders first; subtle elevation reserved for major/floating emphasis.
  • Focus ring: 2px indigo (primary) with 2px surface separation.
  • Dedicated contrast-verified semantic token pairs for info / success / warning / error.
  • Complete Material 3 system-ui typescale only — no monospace utility role.
  • Feedback = required message + optional heading + fixed semantic Lucide-equivalent inline SVG icons (Info / CircleCheck / TriangleAlert / CircleX); no action controls; no custom icon API.
  • Live-region behavior is explicitly consumer-owned — no live-region code appears here.
  • MP-02 excludes shell, production routing, board adapter, chess behavior, stored data, and engines — none appear here.
Honesty note: all hex values are a conceptual tonal derivation from the indigo seed (hue ≈ 231°, Tonal-Spot-style tone mapping). They must be replaced or validated against the official Theme Builder export before any adoption; contrast claims are pending that verification.

Target reviews: 1920×1080 desktop and Pixel 8a portrait at 412×915 CSS pixels. The feedback matrix collapses to one column below 700px; swatch grids auto-flow. Static specimens only — nothing is interactive, and no motion is used anywhere (reduced-motion safe by construction).

3 Treatment principles

Complete state

Material, turn, castling, en-passant, halfmove, and fullmove state are all stated explicitly.

Stable reading order

Occupied squares are announced from a8 through h1 even when the visual board is flipped.

Read-only boundary

The description reports the position and never implies moves, analysis, or other interaction.

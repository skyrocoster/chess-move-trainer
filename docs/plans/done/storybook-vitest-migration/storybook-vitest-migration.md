# Storybook Vitest migration - Storybook stories run as deterministic Vitest 4 browser tests without the legacy runner.

> **Status:** done - all stages complete

- **Read trigger:** Read before implementing or validating the Storybook Vitest 4 migration.
- **Upstream:** Approved coordinator case packet; no master Plan. Reference: [Storybook Vitest addon migration guide](https://storybook.js.org/docs/writing-tests/integrations/vitest-addon/migration-guide).

## Outcome

Frontend Storybook stories run through `@storybook/addon-vitest` as Vitest 4 browser-mode component tests using Playwright Chromium, while the existing jsdom unit-test project, Storybook UI, and separate Playwright end-to-end harness remain usable. The legacy Jest-based Storybook test-runner and its required running-Storybook test flow are removed, giving the team a cleaner and more deterministic test command.

## Scope

Preserve the existing 21 story files, their `storybook/test` imports, and all existing play-function behavior. Preserve the constrained shell story semantics at `412x915`.
- **Expected areas:**

# Chess Move Trainer

Windows-focused FastAPI and React application for practising chess moves.

## Repository map

- [Backend](backend/README.md)
- [Frontend](frontend/README.md)
- [Python source and repository tools](src/README.md)
- [Tests](tests/README.md)
- [Data](data/README.md)
- [Documentation](docs/README.md)

Use the `sg` developer CLI (`uv run --no-sync sg --help`). Start, stop and
inspect the services with the commands in
[`docs/DEVELOPMENT_SERVICES.md`](docs/DEVELOPMENT_SERVICES.md), and run tests as
described in [`docs/TESTING.md`](docs/TESTING.md). Repository rules for
contributors and agents are in [`AGENTS.md`](AGENTS.md).
